# NetSwitch

[English](#english) | [Русский](#русский)

---

<a name="english"></a>
 🇬🇧 English

A lightweight C# WinForms utility for quickly switching and managing network adapters on Windows.

 Features
* Fast network adapter switching.
* Simple and user-friendly interface.
* Built with C# and Windows Forms.

 Tech Stack
* **Language:** C#
* **Framework:** .NET / Windows Forms
* **Platform:** Windows

 Getting Started
1. Clone the repository or download the source code.
2. Open `NetSwitch.sln` in Visual Studio.
3. Build and run the project.
